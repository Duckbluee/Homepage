title: Agriculture Q&A System Based on Knowledge Graph
date: 2022-12-01
tags:
  - Knowledge Graph
  - Natural Language Processing
  - Neo4j
---

Developed a knowledge graph-based question answering system for crop disease inquiries, using web-crawled data, BERT-BiLSTM-CRF entity extraction, and Neo4j storage.

The system linked user queries to entities and relations in the knowledge graph and achieved over 65% accuracy in the application setting.
